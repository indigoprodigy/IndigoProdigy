# Independent Demonstrations

This folder contains standalone educational samples created specifically for this public portfolio.

These examples are not exports, previews, simplified versions, or documentation of any UniversoulCo or Indigo Prodigy production system. They are not connected to private infrastructure, accounts, APIs, databases, or internal workflows.

## Demonstrations

- [Standalone Color Study](standalone-color-study.html) — a browser-only exercise in exploring generic color combinations.

## Isolation rules

- Fictional/sample content only.
- No production credentials, external APIs, analytics, databases, or account integrations.
- No imports from private projects or internal repositories.
- No representation that a sample is a deployed product or production capability.
- Keep actual systems, source code, roadmaps, and internal documentation outside this repository.
