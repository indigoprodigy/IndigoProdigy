# Selected Projects

This directory is the public index for selected Indigo Prodigy and UniversoulCo projects that are ready to share.

Only publish work that has been reviewed for ownership, permissions, privacy, and disclosure risk. A project does not belong here merely because it exists.

## Publication status

Projects may be listed using these statuses:

- **Public** — approved for unrestricted public viewing.
- **Demo** — a limited demonstration with no private infrastructure or production credentials.
- **In development** — mention only when the existence and description of the work are approved for disclosure.

## Project entry template

Copy this structure for each approved project:

### Project name

One-sentence description of the public-facing purpose.

- **Status:** Public / Demo / In development
- **Role:** Creator / Founder / Developer / Collaborator
- **What it demonstrates:** A concise description of the visible work
- **Public link:** Add only after checking that the destination is safe to share
- **Ownership and permissions:** Confirmed before publication
